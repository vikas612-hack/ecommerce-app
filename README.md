# Ecommerce App

A React-based Ecommerce Application.

## Features

- Product Listing
- Category Filtering
- Search Products
- Add To Cart
- Remove From Cart
- Quantity Management
- Wishlist
- Checkout Page
- EmailJS Order Confirmation
- Responsive Design
- Context API
- React Router
- Local Storage Persistence

## Technologies Used

- React.js
- React Router DOM
- Context API
- EmailJS
- CSS3

```bash
npm install
npm start
